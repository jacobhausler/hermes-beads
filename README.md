# Hermes Beads workbench

Native Beads (bd) work-graph plugin for Hermes. Native Beads remains authoritative — stock `bd` alone stays fully sufficient (escape-hatch law); this plugin only reduces agent effort. Workflow integration is optional and fully additive.

## Install

```
hermes plugins install jacobhausler/hermes-beads
```

See `docs/hbi-boundary.md` for the plugin/b9s boundary, and the docs/ ledgers (`native-capabilities.md`, `content-guard-contract.md`, `interop-capabilities.md`) for the tested native-capability contract.
